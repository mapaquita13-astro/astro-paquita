- Les trois types sont câblés : questions gratuites, jours Premium, réduction %.

- Les erreurs distinctes sont gérées : code invalide, expiré, déjà utilisé, limite atteinte, indisponibilité paiement et abonnement Premium déjà actif.
- Une réduction % reste appliquée au checkout Stripe sans modifier le fonctionnement Stripe historique.
- Protection backend 23/09 : un compte possédant déjà un abonnement Stripe Premium actif ne peut pas appliquer un code « jours Premium » qui créerait une date d’expiration locale contradictoire. Le backend répond sans consommer le code.
- Pour un compte sans abonnement Stripe actif, le code « jours Premium » prolonge une éventuelle période Premium temporaire existante ou démarre à la date courante.
